# Oba Chocolate

Envie todos os arquivos desta pasta para a raiz do repositório GitHub.

Os arquivos principais mantêm os nomes tradicionais na raiz:

- `index.html`
- `styles.css`
- `script.js`
- `loja.html`
- `loja.js`

As imagens também ficam nesta mesma pasta. Não envie a pasta-pai `output`; envie somente o conteúdo desta pasta.
